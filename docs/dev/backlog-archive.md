# Archive du backlog

Les items livrés, une ligne chacun. Ils restent ici pour qu'un `#N` cité dans un
commit, une pull request ou `AGENTS.md` mène toujours quelque part : un numéro
n'est jamais réutilisé ni renuméroté.

Le récit de chaque version est dans le [CHANGELOG](../../CHANGELOG.md) ; ce qui
reste à faire est dans le [backlog](backlog.md).
